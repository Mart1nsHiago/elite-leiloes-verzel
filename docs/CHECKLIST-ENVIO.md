# Checklist — envio do teste técnico Verzel

O PDF da Verzel solicita **repositório público** e **link de deploy obrigatório**.

## Antes de enviar

- [ ] Subir todo o projeto para um repositório **público** no GitHub.
- [ ] Executar a pipeline de CI (testes da API e build React) e corrigir eventuais erros.
- [ ] Fazer deploy e confirmar que o endereço público abre.
- [ ] Confirmar `/api/health` e `/docs` no endereço público.
- [ ] Entrar com um licitante, oferecer lance e verificar atualização na sala.
- [ ] Abrir o mesmo lote em duas janelas de usuários distintos; verificar superação e liberação de saldo.
- [ ] Abrir a auditoria pública em janela anônima.
- [ ] Abrir um comprovante em janela anônima usando Ana → Meus arremates → A Metamorfose.
- [ ] Publicar um novo livro pelo painel do leiloeiro (Open Library/fallback).
- [ ] Verificar se o ambiente publicado está acessível de outra rede, inclusive no celular.
- [ ] Atualizar o README, se houver ajustes no fluxo ou no ambiente publicado.
- [ ] Declarar precisamente o uso de IA, sem alegar revisão que não tenha feito.
